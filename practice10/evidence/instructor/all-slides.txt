Why risk review matters
--- PAGE 9 ---
● Correctness: invalid availability decisions or missing boundary 
cases.
● Security / privacy: secrets, unsafe dependencies, untrusted input 
or data exposure.
● Reliability: flaky tests, inconsistent builds or time-dependent 
behavior.
● Agent operations: excessive permissions, unreviewed edits and 
shared resources.
Review AI-assisted software for risks
Risk categories
--- PAGE 10 ---
● Risk: a plausible event with a potential adverse consequence.
● Finding: observed evidence such as failing tests or missing 
safeguards.
● Mitigation: a focused change that reduces likelihood or impact.
● Residual risk: what remains after the mitigation is verified.
Review AI-assisted software for risks
Risk vs. finding vs. mitigation
--- PAGE 11 ---
● Likelihood: 1 unlikely, 2 possible, 3 likely.
● Impact: 1 minor, 2 moderate, 3 serious.
● Risk score = likelihood × impact (range 1–9).
● Prioritize high-scoring risks, but justify each score with evidence.

Lecture #10: what breaks agents
--- PAGE 15 ---
● Sufficient tests and repeatable build / verification commands.

Lecture #10: agent-ready checklist
--- PAGE 16 ---
● Level 1 - Baseline: formatter, linter, type checks, unit tests, 
pinned dependencies.
● Level 2 - Documented: .env.example, architecture notes and 
AGENTS.md.
● Level 3 - Agent-ready: CI, hooks, integration checks and 
reviewable evidence.
● Use these lecture levels as an audit rubric, not an automatic 
certification.
Review AI-assisted software for risks
Repository readiness levels
--- PAGE 17 ---
● A remote agent may modify files while the developer is away.
● Parallel tasks can conflict through shared ports, databases or 
branches.
● Unclear permissions can allow unnecessary external actions.
● Require isolated branches/worktrees, test evidence and human 
approval.

Review AI-assisted software for risks
Sandbox
An AI sandbox is an isolated, controlled execution environment 
where AI coding agents, LLM tool calls, or AI-generated code run 
away from your host machine and production systems.
Developers use AI sandboxing to let agents execute code freely 
while keeping the host and its credentials out of reach.
