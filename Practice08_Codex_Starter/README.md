# Software Engineering Lesson #08 / Practice Work #08 — Codex starter

This is a **starter kit**, not a completed submission or proof of tests. It contains exactly specified Skill instructions, supported optional UI metadata, prompt templates, report outline, checklists, and a stand-alone master prompt for Codex.

## How to use
1. Open your **existing Smart Campus project** in the IDE.
2. Copy the contents of `CODEX_MASTER_PROMPT.md` into Codex. It is intentionally self-contained; attach the Lesson #08 PDF if Codex can accept the file.
3. Optionally place this starter folder in the project root so Codex can reuse the files. Do not overwrite existing project files.
4. Have Codex inspect actual code and preserve baseline, create separate controlled bugs, generate real tests and deliver editable `.docx` report.
5. Complete the manual requirements in `templates/MANUAL_STEPS.md` (Skill written by hand, two independent AI sessions, real screenshots, live URL).
